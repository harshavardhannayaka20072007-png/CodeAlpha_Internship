🚀 Tasks Overview
Task 1: Iris Flower Classification
Objective: Build a machine learning model to classify iris flowers into three distinct species (Setosa, Versicolor, and Virginica) based on their sepal and petal measurements.

Dataset: Iris.csv

Key Steps:

Data loading and exploratory data analysis (EDA).

Data preprocessing and feature-target splitting.

Training a classification model (e.g., K-Nearest Neighbors / Decision Trees).

Evaluating model performance using accuracy scores and classification reports.

Task 2: Unemployment Analysis
Objective: Analyze unemployment rates (especially during the COVID-19 pandemic) across different regions using data visualization techniques.

Datasets:

Unemployment in India.csv

Unemployment_Rate_upto_11_2020.csv

Key Steps:

Cleaning and merging unemployment datasets.

Analyzing regional trends and temporal changes.

Generating visual plots highlighting the impact of COVID-19 on employment metrics.

Automatically exporting generated graphs (covid_unemployment_trend.png and regional_unemployment.png) directly into the task folder.

🛠️ How to Run the Projects
Make sure you have Python and the required libraries (pandas, numpy, matplotlib, seaborn, scikit-learn) installed in your environment.

python task1/iris_classification.py
2. Run Task 2:
