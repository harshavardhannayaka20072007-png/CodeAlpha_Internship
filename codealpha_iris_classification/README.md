# CodeAlpha - Iris Flower Classification

## 📌 Project Overview
This project is part of my Data Science Internship at **CodeAlpha**. The objective is to build a machine learning model that can classify Iris flowers into their respective species (Setosa, Versicolor, or Virginica) based on their sepal and petal measurements.

## 📂 File Structure
* `Iris.csv` - The dataset containing flower measurements.
* `iris_classification.py` - The Python script for training and evaluating the model.
